### 🏭 ITA — Industrial ERP & WMS
Manufacturing and warehouse platform for a plastic-container plant, built by a ~12-person team and running in production. I own material reception, picking lists, SAP sync, tool-crib integration, supplier non-conformities and production-order aggregates.

**Stack:** `TypeScript` `Express 5` `Prisma` `PostgreSQL` `React 19` `React Native` `Expo`

**Highlights:**
- 80+ REST controllers · 100+ DB entities · end-to-end product traceability
- Live per-shift scrap calculation pushed to operator tablets via SSE
- Quality control with pallet traceability and certificate generation
- 2 mobile apps (production floor + logistics)
- Agent-assisted dev: MCP server over the live schema, security-review subagents on every diff

<sub>Private repos under <a href="https://github.com/LTM-Software">LTM Software</a></sub>

</td>

<td width="50%" valign="top">

### 🏎️ BFMC Waypoint Planner
Offline route planner for the **Bosch Future Mobility Challenge 2026**. Models the task as an Orienteering Problem over a Lanelet2 graph: all-pairs Dijkstra cost matrix + hybrid solver (greedy → 2-opt → Or-opt → Simulated Annealing). Outputs annotated SVG, JSON plans and GIF/MP4 animations.

**Stack:** `Python` `Lanelet2` `Pytest (46 tests)`

[![Repo](https://img.shields.io/badge/JoacoMarc-bfmc--waypoint--planner-181717?style=flat-square&logo=github)](https://github.com/JoacoMarc/bfmc-waypoint-planner)

<br/>

### 📈 Stock Market Prediction with ML
NLP + technical-analysis pipeline: FinBERT sentiment inference on financial news combined with 34 technical indicators, feeding a Random Forest classifier validated with rolling-window backtesting.

**Stack:** `Python` `PyTorch` `Hugging Face` `scikit-learn` `Pandas`

[![Repo](https://img.shields.io/badge/JoacoMarc-Stock--ML-181717?style=flat-square&logo=github)](https://github.com/JoacoMarc/Stock-Market-Prediction-with-Machine-Learning)
